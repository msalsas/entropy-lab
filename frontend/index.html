Verbalized estimate vs. true entropy

Each point is a trial. If a model detects its own entropy, self points cluster around an increasing trend (high r); if it confabulates, the cloud shows no correlation. The cross condition is the baseline with the same textual information.

Correlation by condition

Pearson's r between the estimate (0-10) and true entropy (nats), pooling both generators. The "per question" series aggregates each question to a single point to avoid pseudoreplication.

Comparative judgment: which answer was more unpredictable?

The judge sees two answers to the same question (one at low and one at high temperature, randomized order) and must pick the more unpredictable one. The correct answer is objective: the one with higher true entropy. The line marks chance (50%).

Gradient-inversion attack

Large entropy gaps are produced by degenerate high-temperature text. With the original prompt ("unpredictable word choices"), cross judges read broken text as defective, not unpredictable (11%). With an entropy-literate prompt explaining that broken text is the signature of maximum randomness, the failure mostly vanishes (56%): the inversion was conceptual, not perceptual. The 100% self score on degenerate pairs also collapses (50%): another surface heuristic.
